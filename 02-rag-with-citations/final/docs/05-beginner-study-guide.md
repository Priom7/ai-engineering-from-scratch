# Beginner Study Guide

If you are learning RAG for the first time, study this project in this order:

1. run the app
2. upload one short text file
3. ask one obvious question from that file
4. inspect the citations
5. read the backend chunking code
6. read the similarity ranking code
7. read the Ollama embedding and chat calls

## Good first experiments

- reduce chunk size and see how retrieval changes
- upload two documents with similar topics
- ask a question that is not answerable
- compare good retrieval and bad retrieval behavior
