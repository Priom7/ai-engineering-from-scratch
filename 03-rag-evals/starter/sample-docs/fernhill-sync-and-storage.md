# Fernhill Cloud Sync and Storage

Fernhill Cloud is a fictional file-sync service for small teams, used as sample data for this project. This guide covers the desktop app, file limits and recovering files.

## Desktop app

The desktop app runs on Windows 10 or later and macOS 13 or later. Selective sync lets each member choose which folders are stored on their computer.

## File size limit

A single file can be up to 50 GB when uploaded with the desktop app, and up to 5 GB through the web.

## Version history

Fernhill keeps earlier versions of every file for 30 days on Starter and 180 days on Team and Business. Restore a version from the file's History panel.

## Recycle bin

Deleted files stay in the recycle bin for 30 days, then they are removed permanently. Admins can empty the bin sooner.

## Sharing links

Anyone with edit access can create a sharing link. Links can have a password and an expiry date. On Business, admins can set a maximum expiry for every link in the team.

## Bandwidth

Sync is not throttled, but members can limit upload speed in the desktop app's settings.
