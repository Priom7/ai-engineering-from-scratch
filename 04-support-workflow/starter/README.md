# Support workflow: starter

> **This is the starter version.** The app, the API and the workflow file are done, but the engine's core
> functions are `TODO`s. Follow the Build video, or see `../final` for the finished code.

See [the project README](../README.md) for the videos and the list of TODOs.

```bash
npm install
npm test        # 23 tests pass and 19 fail until the TODOs are done
```

When `npm test` passes, run `npm run dev` and press **Run** on the Workflow view. It needs Ollama with
`llama3.2:3b`, `qwen2.5:7b-instruct` and `nomic-embed-text`.
