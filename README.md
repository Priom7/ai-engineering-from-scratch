# AI Engineering From Scratch

Twelve AI systems, built from scratch. They start with a local chat app and end with a production platform. Every project runs on an 8 GB laptop with open models through [Ollama](https://ollama.com), so you don't need API keys or a cloud bill.

Each project comes with three videos on [YouTube](https://www.youtube.com/@iamsharifalam):

- **Concept:** how the idea works, with diagrams
- **Build:** the full implementation, step by step
- **Ship:** the finished product and what it took

## How each project folder works

Each project has two folders:

- `starter/` has the structure and `TODO` comments. Code along with the Build video here.
- `final/` has the finished, working version.

## What you need

- Node.js 22 or newer
- [Ollama](https://ollama.com) with a small model, for example `ollama pull llama3.2:3b`
- About 8 GB of RAM

## Homework challenges

Every Build video ends with a challenge. Open a pull request with your solution; the best ones get featured at the start of the next Build video.
